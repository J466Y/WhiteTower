# Requests for comments

An RFC proposes a change to the module contracts (`api/proto`, `api/events`, `api/manifest`, `api/policy`, and what the conformance vectors in `test/conformance/vectors` expect) or to the project's governance. It exists so that every module author affected by a change can see it coming and influence it. The process is described in [GOVERNANCE.md](../../GOVERNANCE.md#rfc-process), with the provisional acceptance that applies while the project has a single maintainer and no external reviewer; the template is [0000-template.md](0000-template.md).
